# Eski Analizler (2012-2025)

Bu klasor, projenin 2012-2025 tam veri seti donemine gore yazilmis eski notebook ve script dosyalarini icerir.

Proje artik **yalnizca 2021 ve sonrasi** veri seti ile ilerlemektedir. Yeni analiz omurgasi proje kok dizinindeki `00_` - `04_` notebook'larinda bulunur.

## Icerik

- `data-cleaning.ipynb`: Hava verisi cekme ve eski birlestirme islemleri
- `donem_karsilastirma.py`, `gunluk_talep.py`, `mekan_tercihi.py`, `satis_davranisi.py`: Donem bazli analiz scriptleri
- `kapali_gun_analizi.py`: Kapali gun analizi (2021+ mantigi yeni `00` notebook'una tasindi)
- `post2021_yeni_yapi/`: Onceki 2021+ pipeline denemesi
- Diger notebook'lar: EDA, oturum suresi, istatistiksel rapor vb.

Bu dosyalar referans amaclidir; aktif gelistirme bu klasorde yapilmaz.
